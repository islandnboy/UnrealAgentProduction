# Designer Artifact Set

포트폴리오용 Case Study 하나는 다음 Artifact를 한 묶음으로 구성합니다.

## 01 — Request

~~~text
기획자 자연어 요청
~~~

무엇을 만들고 싶은지, 무엇을 보존해야 하는지, 어떤 느낌을 원하는지를 보여줍니다.

## 02 — Production Contract

~~~text
Goal
Scope
Requirements
Acceptance
~~~

자연어가 어떤 실행 계약으로 바뀌었는지 보여줍니다.

## 03 — Agent Trace

~~~text
Workflow / Step
Skill
Actual Tool
Artifact
Validation
Next Action
~~~

Agent가 실제로 어떤 경로로 작업했는지 보여줍니다.

## 04 — Unreal Result

권장 공개 이미지:

- before
- first production result
- designer-corrected result
- final accepted result

가능하면 같은 camera / viewport 기준으로 비교합니다.

## 05 — Evidence

기술적 근거 중 포트폴리오에 의미 있는 것만 요약합니다.

예:

- generated actor count
- input / output coverage
- save / reload
- geometry consistency
- collision / runtime readback
- regeneration safety

대용량 로그 전체를 공개할 필요는 없습니다.

## 06 — Designer Review

~~~text
좋았던 점
문제점
수정 지시
직접 Editor에서 수정한 값
최종 승인 여부
~~~

기획자의 판단 역시 결과물의 일부로 남깁니다.

## 07 — Iteration

~~~text
Initial result
→ Designer review
→ Focused correction
→ Validation
→ Accepted result
~~~

이 한 묶음이 Agent Workflow 포트폴리오의 기본 Case Study 단위입니다.
